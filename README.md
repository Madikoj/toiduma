## 📱 iPad / iPhone арқылы (компьютерсіз)
1. **API кілтін ал (тегін):** https://www.eulerstream.com → тіркел → Dashboard → API key жаса.
2. **Ойынды аш:** Safari-де → https://madikoj.github.io/toiduma/
3. Шыққан «Баптау» терезесіне TikTok логиніңді және API кілтін жаз → «Эфирге қосылу».
   (Кілт тек сенің құрылғыңда сақталады, GitHub-қа түспейді.)
4. TikTok қосымшасы: **+ → LIVE → Mobile Gaming** → Go LIVE → Safari-ге қайт.
5. Safari-де «Бөлісу» → «Басты экранға қосу» — сонда ойын толық экранда ашылады.

**Пайдалы сілтемелер:**
- `?test=1` — тест батырмалары әрдайым көрінеді
- `?debug=1` — эфирден келген оқиғалар экранда жазылады (қате іздеу үшін)
- Баптауды қайта ашу: экранның **сол жақ жоғарғы бұрышын 3 рет бас**

## 🎵 Музыка
Баптау → 🎵 Музыка:
- **Домбыра әуені** — ойын өзі шығарады (төбелесте жылдамдайды, тойда баяулайды, вальста 3/4).
- **YouTube сілтемелері** — әр жолға бір сілтеме (бейне не плейлист) → 💾 Сақтау. Той/вальс кезіндегі арнайы ән де қоюға болады. Ән сахнадағы «📺 Той теледидарында» ойнайды (YouTube ережесі бойынша ойнатқыш көрініп тұруы керек). Теледидардың орнын ауыстыру: үстіндегі жазуды бас.
- **Өз әндерім** — iPad «Файлдар» ішіндегі mp3/m4a.

⚠️ TikTok авторлық құқығы бар әндерді эфирде өшіріп тастауы мүмкін.

## 💻 Компьютер арқылы (өз серверіңмен)
```
npm install
node server.js СЕНІҢ_ЛОГИНІҢ
```
TikTok LIVE Studio / OBS → Browser source → `http://localhost:8080/?clean=1`, 1080×1920.

## Баптау
